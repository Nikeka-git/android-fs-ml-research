## Быстрая проверка

Python 3.12+, стандартная библиотека, запуск из корня репозитория:

```bash
python tools/verify_research_sources.py
python tools/verify_research_sources.py --fetch
```

Первая команда работает с локальными материалами; вторая дополнительно проверяет публичные источники по HTTPS. Эти тексты предназначены для разработки парсера. Они не являются подтверждёнными ACK-испытаниями или готовым обучающим набором Android-экспериментов.
