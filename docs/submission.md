# Комплект для формы апробации

Основание — предоставленное объявление. Отдельные официальные требования к содержанию и оформлению отчёта пока не получены.

Форма: <https://forms.cloud.microsoft/r/Yy6AXT5pe3>.

Действующие ссылки: [закрытый репозиторий](https://github.com/Nikeka-git/android-fs-ml-research) · [общая доска](https://github.com/users/Nikeka-git/projects/1).

Файлы комплекта: [предварительный PDF-отчёт](report/aprobation-report-draft.pdf), [его редактируемый HTML](report/aprobation-report-draft.html), [отдельный PDF со скриншотами доски и задач](report/board-screenshots.pdf). Полноту отчёта ещё нужно сверить с официальными требованиями.

## Сведения и материалы

- Форму заполняет **один представитель команды от имени всех участников**.
- Указываются тема, данные руководителя, ФИО и GitLab-аккаунты всех участников, индивидуальный вклад, ссылка на репозиторий и ссылка на YouTrack или схожую систему.
- **Первый PDF:** скриншоты доски **и отдельных задач** YouTrack или схожей системы, объединённые в один файл.
- **Второй PDF:** единый отчёт со всеми разделами, предусмотренными требованиями к апробационному периоду.
- **До отправки** руководитель и комиссия должны получить доступ ко всем материалам по ссылкам. При отсутствии доступа соответствующие результаты проверить и оценить не смогут.

**Срок из объявления: до 18:00 24 октября 2026 года.** После этого времени форма закрывается, приём ответов прекращается. Часовой пояс в объявлении не указан.

## Что пока мешает считать комплект готовым

| Пункт | Текущее состояние |
|---|---|
| Тема и имена автора/руководителя | Указаны в README; официальный формат ФИО требует подтверждения |
| Два остальных участника и GitLab-аккаунты всей команды | Данные ожидаются |
| Индивидуальный вклад | Требует согласования и связи с фактическими материалами |
| Репозиторий и доска в облаке | Созданы; для всех модулей используются один закрытый репозиторий и одна доска GitHub Project |
| GitHub вместо запрашиваемых GitLab-сведений | Допустимость общего репозитория GitHub нужно уточнить; GitLab-аккаунты участников отдельно запрошены объявлением |
| PDF со скриншотами | Отдельный файл указан выше; перед отправкой нужно проверить читаемость и соответствие реальным задачам и статусам |
| Полный отчёт | Разделы официальных требований неизвестны; предварительный черновик не подтверждает полноту |
| Доступ руководителя и комиссии | Не проверен; репозиторий Private, учётные записи получателей для выдачи прав ещё не предоставлены |
| Представитель команды и отправка | Представитель не определён; форма не отправлена |

Сохранённые JUnit XML и lint-отчёт являются отдельными исходными подтверждениями с ограничениями, описанными в [evidence.md](evidence.md). Они не заменяют два требуемых PDF и не подтверждают полноту дипломной темы.

В отчёте нужно описывать фактическое состояние каждого модуля отдельно. Сейчас предоставлен диагностический модуль `binder-diagnostics`; шаблоны будущих модулей не являются готовыми реализациями.
