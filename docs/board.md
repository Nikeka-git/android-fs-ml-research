## Статусы и поля

| Статус | Значение |
|---|---|
| Todo | Работа запланирована; критерии ещё не выполнены |
| In Progress | Работа начата или выполнена частично; оставшиеся критерии сохранены в задаче |
| Done | Доступный результат соответствует критериям и связан с подтверждающим изменением |

Приоритеты: **P1 - High** — задачи сдачи и ключевые материалы, **P2 - Medium** — вспомогательная проверка и подготовка. Срок **2026-10-24** означает включение результата в комплект сдачи этапа, а не восстановленный первоначальный срок разработки. Для задач без известного срока значение оставлено незаданным. Ретроспективные R01–R11 зарегистрированы по фактическим коммитам; дата создания issue не выдаётся за дату выполнения исходной работы.
