# Доска задач

Доска общая для всего монорепозитория: [GitHub Project](https://github.com/users/Nikeka-git/projects/1), представление **Board**. Она связана с [репозиторием](https://github.com/Nikeka-git/android-fs-ml-research); его GitHub Issues доступны по ссылке. Настройка доски и статусы ниже зафиксированы в материалах от 15 октября 2026 года и не являются новым снимком текущего состояния.

В теле каждой задачи указывается `module_id` либо область `shared`. Задачи будущего модуля помечаются как предложения до его регистрации. Все стартовые задачи запланированы, исполнители не назначены. Даты начала, завершения и оценки трудозатрат не установлены.

## Колонки

| Колонка GitHub | Значение в документации | Условие использования |
|---|---|---|
| Todo | Запланировано | Работа ещё не начата; уточнение объёма и готовность к работе отмечаются в самой задаче |
| In Progress | В работе | Исполнитель действительно приступил к задаче; ожидание проверки отмечается в самой задаче |
| Done | Готово | Критерии выполнены, результат проверен и связан с задачей |

Если возникло препятствие, отметьте задачу признаком «Заблокировано» и опишите конкретную причину. Не меняйте её основной статус без фактического перехода.

## Предложение будущего распределения

После обсуждения можно распределить три направления между тремя участниками:

- организация требований, отчёт и связь задач с материалами;
- описание экспериментального стенда и протокола;
- план данных, модели и оценки результатов.

Это предложение направлений, а не назначение конкретным людям. Итоговые роли, исполнители и объём работы определяются после получения данных команды и изучения уже выполненной работы. Каждый участник проверяет задачи других в пределах своей компетенции; проверяющий назначается отдельно.

Ответственность за модуль назначается отдельно от общего направления. Сейчас в реестре два модуля; наличие импортированных снимков не подтверждает завершение ML-реализации. Уточнённые сведения о команде и предлагаемые обязанности следующего этапа находятся в [team.md](team.md).

Публичный доступ к репозиторию не определяет видимость отдельной доски GitHub Project. PDF со скриншотами от 15 октября хранится отдельно: [board-screenshots.pdf](report/board-screenshots.pdf). Для проверки актуальных задач используются [GitHub Issues](https://github.com/Nikeka-git/android-fs-ml-research/issues).
