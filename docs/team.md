## Задачи и ревью

YouTrack не используется; ID YouTrack отсутствуют. Реальные задачи GitHub доступны в [Issues](https://github.com/Nikeka-git/android-fs-ml-research/issues), соответствие локального плана опубликованным задачам — в [planning/published-issues.json](../planning/published-issues.json). По этим плановым записям нельзя приписать выполненную работу конкретному участнику. Подтверждённых индивидуальных ID завершённых задач и ссылок на взаимные ревью для этой версии не предоставлено.

История до подготовки апробационной документации содержит три коммита аккаунта Nikeka-git; соавторские записи для Kerey404 и aliiyaaa в том историческом снимке отсутствуют. Проверка и согласование задач остаются отдельными действиями. Подтверждённые взаимные ревью и завершённые индивидуальные материалы aliiyaaa пока не добавлены.
