# Общие компоненты

Здесь размещаются библиотеки и форматы, которые действительно используются несколькими модулями. В текущем снимке общий исполняемый код не добавлен.

Выделение общей библиотеки оформляется отдельной задачей: назначение, зависимые модули, версия интерфейса и способ проверки. До появления общей реализации каждый модуль сохраняет собственную систему сборки.
