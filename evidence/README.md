# Происхождение и подтверждения

Этот раздел связывает заявления о проекте с конкретными файлами. Здесь можно проверить состав импорта, контрольные суммы и сохранённые отчёты. Подробное описание границ каждой проверки находится в [полном реестре](../docs/evidence.md).

| Материал | Что подтверждает |

Показатели парсера и ML в совместном отчёте остаются сведениями документа. Исходники описанных программ и журналы в этом пакете отсутствуют; повторный запуск не заявляется.
