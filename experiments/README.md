# Реестр экспериментов

Для каждого реального запуска сохраняйте идентификатор модуля, ревизию кода, конфигурацию окружения, происхождение входных данных, дату фактического запуска и ссылки на результаты. Неудачные и неполные запуски также фиксируются.

Сырые большие или закрытые данные хранятся отдельно. В репозитории остаются метаданные и доступные проверяющим ссылки. В текущем снимке новый эксперимент не проводился; сохранённые прежние отчёты находятся в `evidence/stored`.

Правила подготовки исследовательских данных и проект методики оценки добавлены 24 октября 2026 года: [подготовка данных](../docs/research/data-preparation.md), [методика оценки](../docs/research/evaluation-methodology.md), [реестр публичных текстов](../data/diagnostic-texts/manifest.json). Они относятся к общей области `shared` и текстовому диагностическому компоненту, описанному в Assignment 3. Готового исполняемого текстового модуля в этом изменении нет; это не новый эксперимент `binder-diagnostics` или `android-poc-research`.

Методика содержит шаблон идентификатора запуска, необходимые поля записи, правила парных сравнений, метрики и учёт неудачных/неполных наблюдений. Будущие протоколы сохраняются отдельно по фактическим запускам; пустой шаблон и численные результаты из документа не считаются новым запуском. Модель, телеметрия и экспериментальные данные добавляются после фактического получения и проверки, с указанием использующего их модуля.
