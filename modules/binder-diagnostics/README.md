# NativeBinderDiagnostics

Текущий модуль представляет диагностическую основу: локальную симуляцию и проверку протокола Binder. Статус и ограничения заданы в [module.json](module.json).

## Структура

- `app/src/main` — Android/Kotlin, JNI и C++17.
- `app/src/test` — модульные тесты модели.
- `app/src/androidTest` — исходники Android-тестов.
- `app/src/main/cpp/tests` — исходники нативных проверок.
- `tools` — существующие средства запуска тестов из предоставленного проекта.

Для Gradle-проекта используется эта папка, а не корень монорепозитория. `local.properties` не переносился: локальный Android SDK нужно настроить в своей среде. В конфигурации указаны Java 17, compileSdk 36, NDK 28.2.13676358 и CMake 3.22.1. Сборка этой копии после переноса не проверялась.

Сохранённые результаты находятся в [evidence/stored](../../evidence/stored). Их наличие не означает повторного запуска. Полный перечень перенесённых файлов и SHA-256 находится в манифесте.

Неподключённые legacy-заготовки Phase 3 и старые описания exploit-workflow не включены. Оригинальная папка не изменена. ML, наборы данных и подтверждённая поддержка различных файловых систем в этом модуле не представлены.
