# Шаблон нового модуля

Скопируйте эту папку в `modules/<module-id>` и заполните `module.json`. Шаблон не регистрируется как готовая реализация.

## Назначение и состояние

Указать исследовательскую задачу, фактически реализованные возможности и ограничения. Предполагаемые возможности описывать как план.

## Окружение

Указать только подтверждённые версии платформы и условия экспериментов. Отдельно перечислить проверенные и предполагаемые конфигурации.

## Исходники и проверки

Собственные исходники размещать в `src`, проверки — в `tests`, пояснения — в `docs`, либо использовать естественную структуру выбранной системы сборки. Эта заготовка не содержит исполняемого кода.

## Подтверждения и команда

Добавить ссылки на реальные материалы, протоколы и задачи, ответственных участников и подтверждённый вклад. Затем зарегистрировать модуль в `modules/catalog.json`.
